# nixos-config

Zev's NixOS configuration. Currently targets **ThinkPad L480** (Intel i5-8350U, 16 GB DDR4, 512 GB SSD). Full design / reasoning in [`docs/thinkpad-l480-setup.md`](docs/thinkpad-l480-setup.md). This README is the source of truth for install/rebuild commands.

## Structure

```
flake.nix                          # Flake entry — inputs + nixosConfigurations
hosts/nix/
  configuration.nix                # System-level config for the L480
  hardware-configuration.nix       # Generated by nixos-generate-config (machine-specific)
docs/
  thinkpad-l480-setup.md           # Design spec / reasoning (this README = commands)
```

Hostname is **`nix`**; the flake attribute is **`l480`** (the machine model), so every `nixos-* --flake .#l480`. Dotfiles (bashrc / kitty / starship / vim / tmux) are **manual** — copied from [github.com/zevlo/dotfiles](https://github.com/zevlo/dotfiles), not managed here (see the design spec's Phase 7).

## Inputs (pinned in flake.lock)

- `nixos-26.05` channel (stable)
- `nixos-hardware` (for the `lenovo-thinkpad` module)

## Install on the L480

Prepare the install USB on another machine with the **minimal x86_64 ISO**:

- `https://channels.nixos.org/nixos-26.05/latest-nixos-minimal-x86_64-linux.iso`
- `https://channels.nixos.org/nixos-26.05/latest-nixos-minimal-x86_64-linux.iso.sha256`

Verify the SHA-256, then flash with [balenaEtcher](https://etcher.balena.io/) (Windows/macOS/Linux). Boot the L480 from it (**F12** boot menu, disable Secure Boot). Wired Ethernet is preferred (DHCP is zero-config and makes the install fast).

As root on the live ISO:

```bash
# 1. Partition (this L480 is SATA — /dev/sda. Confirm with lsblk first.)
#    Two partitions only — swap is a declarative swapfile (see configuration.nix).
parted /dev/sda -- mklabel gpt          # destroys existing sda1/sda2 — parted will prompt, confirm yes
parted /dev/sda -- mkpart ESP fat32 1MiB 1025MiB
parted /dev/sda -- set 1 esp on
parted /dev/sda -- mkpart primary 1025MiB 100%

mkfs.fat -F32 /dev/sda1
mkfs.ext4 /dev/sda2

mount /dev/sda2 /mnt
mount --mkdir /dev/sda1 /mnt/boot

# 2. Generate hardware-configuration.nix (we only need this file from it)
nixos-generate-config --root /mnt

# 3. Clone this flake, drop the generated hardware config into it
git clone https://github.com/zevlo/nixos-config.git /tmp/nixos-config
cp /mnt/etc/nixos/hardware-configuration.nix /tmp/nixos-config/hosts/nix/

# 4. Install (set the ROOT password when prompted — used for TTY recovery only)
nixos-install --flake /tmp/nixos-config#l480

# 5. Set zev's password inside the installed system before rebooting
#    (no password lives in the flake — see "First login" below)
nixos-enter --root /mnt -c 'passwd zev'

reboot
```

## First login

The gdm login screen appears — sign in as **`zev`** with the password you set via `nixos-enter` above. Then finish setup:

```bash
# SSH keys (sshd is keys-only — generate the key at the keyboard first)
ssh-keygen -t ed25519 -C "zev@nix" -f ~/.ssh/id_ed25519
gh auth login                            # if not already
gh ssh-key add ~/.ssh/id_ed25519.pub --title "L480"

# the system config (rebuild from here — see "Rebuild after edits")
git clone git@github.com:zevlo/nixos-config.git ~/nixos-config

# dotfiles (manual copy — NOT home-manager)
git clone git@github.com:zevlo/dotfiles.git ~/dotfiles
# then copy starship/kitty/bash/vim/tmux per the design spec's Phase 7
```

### If gdm login ever fails (locked-out recovery)

gdm refuses root, but a virtual terminal does not. From the gdm screen:
**Ctrl+Alt+F3** → log in as `root` (password = the one you set at the `nixos-install` prompt) → `passwd zev` → **Ctrl+Alt+F1** (or F2) back to gdm.

## Rebuild after edits

```bash
cd ~/nixos-config
git pull
sudo nixos-rebuild switch --flake .#l480
```

Upgrades (the `pacman -Syu` equivalent) — `nixos-rebuild` alone does NOT upgrade; bump the lock first:

```bash
cd ~/nixos-config
nix flake update                              # bumps flake.lock → latest nixos-26.05
git diff flake.lock                           # review
sudo nixos-rebuild switch --flake .#l480
git commit -am "nix: bump nixpkgs"
```

## Rollback

Every `nixos-rebuild switch` creates a bootable **generation** (capped at 10 by `boot.loader.systemd-boot.configurationLimit`). Pick the previous one at the systemd-boot menu, or `sudo nixos-rebuild switch --rollback`.
